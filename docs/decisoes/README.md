As DEC-027–DEC-029 detalham empates, posições e tolerâncias dos testes matemáticos.

Os detalhamentos existentes das decisões aprovadas ficam em `aprovadas/`, com acesso pelo registro. As propostas ficam em `propostas/`, com acesso pelo índice da Parte 5. Cada detalhamento tem uma única localização; os índices preservam os identificadores e apontam para o conteúdo completo.

Esta reorganização é editorial. Identificadores, datas de aprovação, conteúdo das decisões e pendências foram preservados. As versões de conteúdo dos documentos de origem foram mantidas; a separação em arquivos não representa nova aprovação.
