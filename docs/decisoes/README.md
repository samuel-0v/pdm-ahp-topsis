As DEC-027–DEC-029 detalham empates, posições e tolerâncias dos testes matemáticos.

Os detalhamentos existentes das decisões aprovadas ficam em `aprovadas/`, com acesso pelo registro. Os caminhos antigos em `propostas/` remetem às decisões aprovadas em 06/11/2026. Cada detalhamento tem uma única localização; os índices preservam os identificadores e apontam para o conteúdo completo.

A reorganização anterior foi editorial. A aprovação conjunta de DEC-039–DEC-042 foi registrada em 06/11/2026, concluindo documentalmente a Etapa 3. Identificadores, datas de aprovação, conteúdo das decisões e pendências foram preservados. As versões de conteúdo dos documentos de origem foram mantidas; a separação em arquivos não representa nova aprovação.
